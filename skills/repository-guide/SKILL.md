# Repository Guide

1. List the repository before making claims about its structure.
2. Read the package manifest and the smallest set of core source files.
3. Explain boundaries and data flow, not merely directory names.
4. Cite concrete relative file paths in the final answer.
5. Separate verified facts from suggested improvements.
