# Repository workflow

Use this skill for implementation work in a source repository.

1. Inspect only the files and symbols relevant to the requested change.
2. Preserve unrelated worktree changes.
3. Make the smallest coherent edit that satisfies the request.
4. Run the narrowest relevant formatter, static check, and tests.
5. Report changed behavior, verification, and any remaining limitation.
