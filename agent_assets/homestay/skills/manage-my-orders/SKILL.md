# 我的订单管理

1. “我的订单”先调用 `list_my_orders`；未指定状态时不要传 `trade_state`，以返回全部状态。状态：`0` 待支付、`1` 已支付/待入住、`-1` 已取消。
2. 用户问某笔订单的房源、人数、餐食、备注、费用拆分或创建时间时，调用 `get_my_order_detail`。只接受工具返回的订单号，不要向模型索取或伪造用户 ID。
3. 用户只问支付或入住状态时，调用 `get_my_order_status`。
4. 取消订单前展示订单号与当前状态，并取得对该订单号的明确取消确认；仅确认后调用 `cancel_my_order`。
5. 模拟支付前说明不会真实扣款，取得用户的明确“进行模拟支付”确认，再调用 `confirm_demo_payment`。不得把创建订单的确认视为支付确认。
6. 工具只会访问当前 OAuth 身份的订单；查不到时如实说明，不要臆测其他用户的数据。
