# 可订性与报价

必需信息：民宿 ID、入住日期、离店日期、入住人数。餐食偏好可选，默认不含餐。

1. 日期必须是完整的 `YYYY-MM-DD`，离店日期必须晚于入住日期；不要猜测年份或把“住两晚”误写成一天。
2. 只问可订时调用 `check_homestay_availability`。
3. 问价格、总价、含餐价格或同时关心可订性时调用 `quote_homestay_stay`，并展示晚数、房费、餐食费和总价。
4. 若 `available=false`，说明日期不可订，可建议替代日期或回到 `find-and-compare` 查找其他房源；不要创建订单。
5. 若用户希望下单，先完整复述最终报价并取得“创建待支付订单”的明确确认，再转入 `booking-workflow`。

报价是即时估算，创建订单时会再次检查冲突；不得承诺预检查已经锁定房源。
